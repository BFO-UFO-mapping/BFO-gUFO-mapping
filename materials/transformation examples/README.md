# BFO-gUFO transformation patterns

## Description

This folder contains examples of UFO-compliant ontologies generated from BFO-compliant resources by applying [transformation patterns](https://github.com/BFO-gUFO-mapping/BFO-gUFO-mapping/blob/main/Transformation%20Patterns%20-%20BFO%20to%20gUFO.pdf). Ontologies are rendered in [Terse RDF Triple Language](https://www.w3.org/TR/turtle/).

  - [GeoCore-U](https://github.com/BFO-UFO-mapping/BFO-gUFO-mapping/blob/main/materials/transformation%20examples/geocore-u.ttl) from [GeoCore](https://github.com/BDI-UFRGS/GeoCoreOntology).
  - [OntoNeo-U](https://github.com/BFO-gUFO-mapping/BFO-gUFO-mapping/blob/main/materials/transformation%20examples/ontoneo-u.ttl) from [OntoNeo](https://github.com/ontoneo-project/Ontoneo).
