# BFO-gUFO-mapping

## Description

This repository hosts the alignment between align with [Basic Formal Ontology (BFO)](https://basic-formal-ontology.org/) and [Unified Foundational Ontology (UFO)](https://ontouml.readthedocs.io/en/latest/intro/ufo.html). Specifically, current alignment stands between OWL implementations of [BFO2020](https://github.com/BFO-ontology/BFO-2020/tree/master/21838-2/owl) and UFO (named [gUFO](https://nemo-ufes.github.io/gufo/)).
